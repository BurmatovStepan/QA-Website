# Сравнение производительности

## 1. Измерения
| Сценарий | Requests per second [#/sec] | Time per request [ms] |
| :--- | :---: | :---: |
| Nginx, статический документ  | 4434.79 | 2.255 |
| Gunicorn, статический документ | 140.12 | 71.366 |

## 2. Анализ
- **Статика | WSGI:** Статический файлы через Nginx отдуются в **31,65** раз быстрее, чем через WSGI.
- **Влияние кэша:** Использование `proxy_cache` ускоряет отдачу страницы в **7,17** раз.
